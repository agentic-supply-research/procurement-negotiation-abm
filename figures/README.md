# Figures

Files include vector PDF, editable SVG, and 600-DPI PNG. The first three `figure0*` diagrams present the conceptual problem and implemented ABM rules; they are **schematics**, not observed networks. `fig0*` figures summarize either the observed negotiation extract or stochastic simulations. They can be regenerated by the Python files in `code/`.

| Prefix | Description | Script |
|---|---|---|
| `figure01_problem_network` | One shared physical network, structured decisions, and alternative bargaining decision authority | `plot_grayscale_framework.py` |
| `figure02_data_to_abm` | GLEE outcome extraction and transfer into the network model | `plot_grayscale_framework.py` |
| `figure03_abm_schedule` | Contract attempt, two-sided decision, flow execution and relationship updating | `plot_grayscale_framework.py` |
| `figure04_stateful_agents` | Supplementary stateful agent policy schematic | `plot_publication_figures.py` |
| `fig02_micro`, `fig03_trajectories`, `fig05_paired_effects`, `fig06_sensitivity` | GLEE and principal simulation comparisons | `regenerate_grayscale_results.py` |
| `fig07_network_snapshots` | Illustrative single-seed trading matrices | `plot_network_snapshots.py` |
| `fig08_emergent_rewiring`, `fig09_shock_link_reuse` | Link turnover, supplier reallocation and recovery-period link reuse | `plot_emergent_links.py` |

Figure numbering in a manuscript can differ from file prefixes; the script names and scientific quantities are stable.
