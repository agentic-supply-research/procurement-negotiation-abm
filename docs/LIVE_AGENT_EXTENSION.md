# From a learned surrogate ABM to live autonomous procurement agents

The reported manuscript results come from **empirically seeded, assumed policy-learning rules**. The current simulation does not contain calls to a deployed LLM. The companion `code/llm_policy_interface.py` defines a future integration boundary for truly autonomous agents with typed actions, separate role-local memories, and contract validity checks.

A future experiment should run independently instantiated buyer and supplier LLMs with isolated message histories, a shared solver for sourcing and capacity-feasibility constraints, and a bounded tool menu (`propose_contract`, `accept`, `reject`, `defer`, `request_capacity_disclosure`, `renew`, `terminate`). Dynamic state must contain last deliveries, prices, response latency, concession history, and a verifiable action audit. Across repeated rounds each agent should use **its own historical observations** to update policies or prompts; if model training is claimed, explicitly describe and train a weight-updating algorithm. The current running model only implements *memory-based adaptation*.

Four role-matched conditions should be collected: H–H, H–AI, AI–H and AI–AI, with the same optimization tool access and economic scenarios. Use true human decisions where a human role is claimed. Store a common event and action schema: `episode_id, period, role, agent_id, partner_id, prompt_version, model_id, tool_version, revealed_capacity, actual_capacity, offer_price, offer_qty, accepted, delivered, elapsed_rounds, breach, renegotiation, renewal, termination`. Fit role-specific policies on training dyad-sequences and validate on held-out economic cases and new opponents. Evaluate whether the learned behavioral kernel reproduces empirical joint agreement rates, concession slopes and relationship trajectories before making claims about general supply-network transformation.

Record model version, temperature, tool calls, prompts, session IDs, rate/cost limits and failure/invalid output rates. Invalid contracts must be rejected by the host constraint layer and counted separately. Human participation requires consent and ethics review. A matching design with repeated interaction and random assignment is needed for causal claims.
